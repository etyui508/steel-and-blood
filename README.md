# 钢与血 · Steel & Blood

> **Minecraft 1.21.1** · **NeoForge 21.1.236** · 137 个模组 · 11 章任务书
>
> 一个把"受伤"当真的硬核枪械生存整合包。
> *A hardcore gun-survival modpack built around realistic trauma — in Chinese.*

枪不是开局就有的，伤不会自己好，血不会自己停，而夜里回来的东西比白天多。
这个整合包围绕一条线来做：**让每一次交火都有代价，让活下来是一件需要计划的事。**

---

## 这是什么

**枪是稀缺品。** 火绳枪 → 手枪 → 步枪 → 狙击，每一步都要蓝图和材料。子弹是从铜板开始做的：
压弹壳 → 装火药 → 压弹头，中期还得靠机械动力把产线架起来。你打出去的每一发都花过时间。

**伤是真的。** 中弹不是掉血条：流血会持续掉血并在地上留下血痕，腿断了跑不动（还可能被锯掉），
头部中弹会脑震荡、视野和准星一起遭殃。**吃饱不再回血** —— 只靠药、绷带和队友。

**枪会坏。** 每开一枪都有概率卡壳，枪管越热、积碳越多越容易；卡住的枪对谁都打不响，
得按住键手动排除故障。

**人会生病。** 在冷地方待久了会感冒，感冒拖久了会变成流感（还会传染给旁边的人），
吃了生肉脏水会拉肚子 —— 药得对上症。

**敌人也有枪，但人也可以站在你这边。** 匪帮会用卓越前线的枪械跟你对射，按世界天数换装备；
而幸存者是中立的，绿宝石能把他招进来 —— 你得给他枪，还得给他喂子弹。

**尸潮有节奏。** 夜晚、血月、连锁尸潮，加上枪声会**把僵尸引过来**（装了消音器就少引一点）。

## 核心机制

| 系统 | 一句话 |
| --- | --- |
| 创伤分级 | 按口径与命中部位决定伤得多重（爆头、断肢、流血、骨折、脑震荡） |
| 尸体与血痕 | 尸体会留在原地、可以被拖动，血会渗在地上并随地表变化 |
| 回血只能靠药 | 被动回血被关闭；金苹果/再生等免费回血会被撤销 |
| 药品与疾病 | 感冒 / 流感 / 腹泻 / 伤口感染，各自的药，吃错药没用 |
| 负重 | 背得多跑得慢，枪的真实重量算在内 |
| 救援 | 给别人包扎、打夹板，或者把人扛走 |
| 枪械手感 | 按弹药能量重标定后坐力，受伤会让枪端不稳 |
| 卡壳与排障 | 过热与积碳积累，卡住之后要手动排除 |
| 消音器 | 压低枪声传播半径，口径越小越安静 |
| 探雷器 | 扇形扫描 + 建筑里随机生成的地雷 |
| 防弹插板 | 降低创伤档次，但护不住头和腿 |
| 持枪 NPC | 匪帮（敌对）与幸存者（中立 → 招募） |
| 最后一个选择 | 按住 Z 把枪口转向自己，再按左键结束 —— 任何时候都能用 |

完整改动历史见 [CHANGELOG.md](CHANGELOG.md)，全部模组见 [模组清单.md](模组清单.md)。

## 键位

这个包改了几个默认键位，**请先看一眼**（游戏内 `设置 → 控制` 都能改）。
原则只有一条：**只挪必须挪的** —— 新机制和"三个模组抢同一个键"的情况才动，其余保持各模组默认。

**本包新增的机制**

| 键 | 功能 | 说明 |
| --- | --- | --- |
| `Z` | 把枪口转向自己 | 按住不放 → 再按左键；松开 Z 可以反悔 |
| `N` | 排除枪械故障 | 卡壳时按住一会儿 |
| `;` | 检视武器 | 把枪翻过来看（`V` 已被"按住说话"和近战占用） |

**为避免冲突而挪走的**

| 动作 | 原键 | 现键 | 为什么 |
| --- | --- | --- | --- |
| 切换射击模式（卓越前线） | `N` | `Y` | `N` 归排障（方向键上下也能切） |
| 关闭语音聊天（简单语音） | `N` | `F7` | 同上，并避开小地图缩放 |
| 切换背包工具（旅行者背包） | `Z` | `[` | `Z` 归自尽 |
| 麦克风静音（简单语音） | `M` | `Insert` | `M` 归地图：原来按 M 会同时开地图+静音+切战术地图 |
| 战术地图（卓越前线） | `M` | `Home` | 与 FTB 地图功能重复 |
| 隐藏任务图标（FTB 任务） | `H` | `,` | `H` 归**身体部位面板**（这个包里常看） |
| TCT 核心按键 | `H` | `\` | 同上 |
| 死亡记录（尸体模组） | `U` | `End` | `U` 归**越肩换肩**（战斗中用得多） |

> 其余按键保持各模组默认。有些默认重叠是**故意保留**的：`V`（按住说话/近战/诱饵）、
> 方向键（越肩视角微调 + 卓越前线切换弹种）、`左Ctrl`（冲刺/屏息）、鼠标左右键（开火/开镜 + JEI 界面操作）
> —— 它们要么只在特定界面生效，要么只在载具里生效，不影响正常战斗。

## 安装

**要求**

- Minecraft **1.21.1** + **NeoForge 21.1.236**（包内已带加载器信息，用启动器自动安装即可）
- **Java 21**
- 建议内存 **6 GB 以上**；这个包有 137 个模组，4 GB 会很难受

**PCL2（推荐）**

1. 下载本仓库 Releases 里的整合包压缩包；
2. PCL2 → 版本设置 → **导入整合包** → 选择压缩包；
3. 首次启动会自动补全依赖，进游戏后先看任务书（开局物资里有一本）。

**手动**

解压后把整个版本文件夹放进 `.minecraft/versions/`，用启动器选中该版本启动。

## 第一晚怎么活

1. 别急着找枪。先把工作台、石剑和火把做出来 —— 这个包里**天亮之前没有枪是正常的**。
2. 开局物资里有绷带和夹板，**别扔**：不流血的时候绷带不消耗，流血的时候它救命。
3. 饿了就吃东西，但记住**吃饱不会回血**；受伤了要靠绷带或药。
4. 别在雨里、雪原上磨蹭太久，感冒不是大事，但流感会传染，而且会让你**打不准**。
5. 听到枪声会引来僵尸 —— 装了消音器会好很多，但枪声依然比你想的响。
6. 看到拿枪的人先躲：**第 6 天之后**你可能会遇到机枪和反器材步枪，而你手里可能还是把手枪。

## 难度调整

绝大多数机制参数都在 `config/sbw_gore-common.toml` 里（按段落分好）。想改难度，通常是这几处：

| 想改什么 | 配置项 | 默认 |
| --- | --- | --- |
| 太容易卡壳 / 太烦 | `jams.jamChancePerShot` | `0.0035` |
| 回血太苦 | `healing.bandageHealing` | `4.0`（两点心） |
| 尸潮里带枪的太多 | `gunNPCs.armedMobChance` | `0.05` |
| 匪帮出现太早 | `gunNPCs.armedMobMinDay` | `2` |
| 疾病太烦 | `diseases.enabled` / `diseases.fluIsContagious` | `true` / `true` |
| 幸存者太贵 | `survivors.recruitCost` | `3`（绿宝石） |
| 机器撑不住 | `performance.lowEndPreset` | `false`（改 `true` 一键降特效） |

改动配置文件后**需要重进世界**（或重启游戏）才生效。

## 常见问题

**按 Z / N / V 没反应？**
先确认你**完全重启过游戏**（不是只退世界）。再去 `设置 → 控制` 看键是不是绑在预期的键上；
如果按键显示正常但没反应，把 `logs/latest.log` 里带 `sbw_gore` 的行发出来。

**绷带 / 夹板用了没反应？**
现在它们会明确告诉你原因（"没什么好包扎的"/"这条腿没有骨折"）。**没伤就不会消耗**，这是设计。

**伤口一直流血停不下来？**
流血需要绷带（或对应药品），血不会自己停。流血层数越多掉得越快。

**为什么我打不动匪帮？**
打头，别站着对射，多利用掩体；他们的枪和你的是同一套弹道，所以你能做的他们也能做。

**太卡怎么办？**
打开 `config/sbw_gore-common.toml` 里的 `performance.lowEndPreset`，再考虑关光影/降视距。

## 反馈

提交 Issue 时请附上：

1. 整合包版本号（例如 `1.25.1`）；
2. `logs/latest.log` 中带 `sbw_gore` 的行；
3. 复现步骤（做了什么、期望什么、实际发生什么）。

自研模组内置了若干自检命令，可以帮你（和我）快速判断问题出在哪一半：

```
/sbwgore jam selftest     # 卡壳拦截是否生效
/sbwgore itemcheck        # 绷带与夹板的判定
/sbwgore healcheck        # 被动回血是否已关闭
/sbwgore selfcheck        # 自尽机制
/sbwgore survivorcheck    # 幸存者招募与弹药
/sbwgore diseasecheck     # 疾病与药品对应关系
```
